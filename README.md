# Grafana Library

Librería pública de recursos visuales para dashboards de Grafana.

Los SVG de `icons/` están diseñados para dashboards oscuros: estilo lineal, consistente, 24x24 y sin dependencias externas.

## URL directa para Grafana

Usa el formato Raw de GitHub:

```text
https://raw.githubusercontent.com/ParksIngDev/Grafana-Library/main/icons/summary.svg
```

Cambia `summary.svg` por el archivo que necesites.

También se incluye `catalog.json` con los nombres y URLs directas para poder reutilizarlos desde configuraciones o scripts.

## Convención visual

- Tamaño base: 24 x 24
- Fondo: transparente
- Trazo principal: #D0D5DD
- Acento: #38BDF8
- Terminaciones redondeadas
- Optimizado para dashboards oscuros de Grafana
